# 古法纸浆发酵记录

运行：

```bash
npm start
```

访问`http://localhost:3039`。数据保存在`data/paper-pulp-fermentation.json`。

## 每日观察的归档规则

- 观察按日期归档，一个批次同一天只有一条记录；当天再次提交会合并更新当天的温度、气味、纤维、换水和异常情况。
- 补录较早日期时，系统按时间顺序重放全部记录，重新算出发酵天数和状态（满 7 天可抄纸）。
- 后来已经出现的可抄纸或异常状态，不会被补录的较早记录顶掉；人工调整的状态同样受保护。
- 批次卡片和顶部统计使用同一套计算结果；卡片上的「详情」可以查看按日期排列的每日观察和日志。
