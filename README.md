# 古法纸浆发酵记录

运行：

```bash
npm start
```

访问`http://localhost:3039`。数据保存在`data/paper-pulp-fermentation.json`。

每日观察按日期归档：

- 观察表单可填日期（默认今天）；同一天重复提交会更新当天的温度、异常等字段，留空的字段保持原值，不会累加天数。
- 补录较早日期时，系统按时间顺序重放全部记录，重新算出发酵天数和每天的状态。
- 已经出现的「可抄纸」或「异常观察」状态不会被较早日期的补录顶掉。
- 批次卡片、详情和顶部统计使用同一份归一化结果；卡片上的「详情」可展开按日期排列的每日记录。
